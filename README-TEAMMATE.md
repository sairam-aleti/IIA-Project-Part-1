# Local Node (police)

This branch contains the local agency database for **police**.

## Instructions
1. Run setup_and_run.bat (Windows) or setup_and_run.sh (Mac/Linux).
2. The server will start locally at http://localhost:8000
3. Run the SSH tunneling command printed in the terminal: ssh -p 443 -R0:localhost:8000 a.pinggy.io
4. Look for the public URL (e.g., https://random.pinggy.link) in the output and text it to the Mediator (the team leader).
